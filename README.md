# 13 November 2026 — The World Today

A magazine-cover-style montage summing up 13 November 2026's world news in one image: a night-side globe ringed by eight vignettes — the Senate summoning Huang, Zelensky meeting US envoys, a drone hitting a warship, Iran striking a US radar site, North Korea's $400m crypto hack, record deportations, the Microsoft outage, and Kane's 126th cap.

This program only copies the generated image `entry.png` into the output directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).
